Step 1 of 12

Install Python

Python is the language we write the game in. Your computer needs to understand it first.

  1. Go to python.org/downloads and download the latest Python 3 (this game needs 3.10 or newer).
  2. Run the installer. On the very first screen, tick the box that says "Add python.exe to PATH" before you click Install. If you miss this, the commands below won't work.

Open a terminal (press the Windows key, type cmd, press Enter) and check it worked

py --version

You should see something like Python 3.14.0.

On Ubuntu, Python is usually already installed, so use python3 --version instead, and if you're missing the venv tool in step 3 run sudo apt install python3-venv.
